# Platform Administration Project

A Spring Boot REST API project for managing platform administration features.

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok
- REST API
- Bean Validation

## Modules

### Manoj
- Super Admin
- Global Dashboard
- Platform Configuration
- Platform Settings

### Prasanth
- Platform Branding
- Feature Management
- License Management
- Platform Health Overview

## Architecture

Controller → DTO → Service → Repository → PostgreSQL
